## What

This PR adds an employee directory and search API for CoreHR. HR admins and authenticated users can now list all employees in their tenant with support for searching, filtering, sorting, and pagination.

**New endpoint:** GET /api/corehr/employees

## Why

This endpoint enables:
- Building an employee directory UI (upcoming Feature 2.4)
- Searching for employees by name or email when assigning managers
- Filtering the workforce by department or employment status
- Browsing large employee lists efficiently with pagination

## Changes

### Pagination Model
- Created PagedResponse<T> with standard pagination metadata (Items, TotalCount, Page, PageSize, TotalPages, HasNextPage, HasPreviousPage)

### Lightweight List DTO
- Created EmployeeListItemDto for directory views
- Includes core fields: name, email, department, job title, status, hire date, manager info
- Excludes audit fields to reduce payload size

### Query + Handler
- GetEmployeesQuery with optional parameters for search, department filter, status filter, sorting, and pagination
- GetEmployeesQueryHandler with tenant isolation, case-insensitive search, page/pageSize validation (1-100), efficient querying

### Controller Endpoint
- Added GET /api/corehr/employees to EmployeesController
- All query parameters optional (defaults: page 1, 20 items, sorted by name)
- Requires authentication
