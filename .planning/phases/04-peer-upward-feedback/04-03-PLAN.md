**1. Create GetFeedbackResponsesQuery + Handler** (D-06: never joins identity, D-08/D-09: threshold suppression, D-12: immediate release)

Query record: GetFeedbackResponsesQuery(Guid CycleId, Guid SubjectEmployeeId, CampaignWorkItemType FeedbackType) : IQuery<Result<FeedbackResponseListDto>>

DTO: FeedbackResponseListDto(IReadOnlyList<FeedbackResponseItemDto> Responses, bool IsSuppressed, int CurrentCount, int MinimumRequired)
DTO: FeedbackResponseItemDto(Guid Id, IReadOnlyList<FeedbackPromptAnswerDto> Answers, string? GeneralComment, DateTime SubmittedAt)
DTO: FeedbackPromptAnswerDto(Guid PromptSnapshotId, string PromptText, int PromptVersion, string AnswerText, bool IsRequired)

Handler logic (CRITICAL: never join FeedbackIdentityMapping):
1. Load PerformanceCycle by CycleId; fail NotFound if missing
2. Read FrozenMinimumAnonymousFeedbackResponses from cycle (governance frozen at publish)
3. Count FeedbackResponseContents WHERE CycleId = @cycle AND SubjectEmployeeId = @subject AND FeedbackType = @type AND Status = Submitted AND IsInvalidated = false
4. If count < minimum → return FeedbackResponseListDto with IsSuppressed = true, empty Responses, counts (D-09: hard suppression — no individual responses, no reviewer identities, no exact count revealed to normal consumers)
5. If count >= minimum → query FeedbackResponseContents (same filter, AsNoTracking) and map to DTOs (D-12: immediate release)
6. NEVER reference FeedbackIdentityMappings in any query or include (D-06)
7. Return FeedbackResponseListDto

**2. Create GetFeedbackThresholdStatusQuery + Handler** (D-08: per-type per-subject cohort)

Query record: GetFeedbackThresholdStatusQuery(Guid CycleId, Guid SubjectEmployeeId, CampaignWorkItemType FeedbackType) : IQuery<Result<FeedbackThresholdStatusDto>>

DTO: FeedbackThresholdStatusDto(Guid CycleId, Guid SubjectEmployeeId, string FeedbackType, int CurrentCount, int MinimumRequired, bool IsSuppressed, bool IsReleased)

Handler logic:
1. Load PerformanceCycle; fail NotFound if missing
2. Count valid submitted responses per cohort (same filter as above)
3. Compare against FrozenMinimumAnonymousFeedbackResponses
4. Return FeedbackThresholdStatusDto with IsSuppressed = count < minimum, IsReleased = count >= minimum
