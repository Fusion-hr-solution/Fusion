<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Reviewer → Controller | Reviewer submits feedback; must own the assigned work item |
| Controller → Identity Mapping | Identity mapping written on submission; read only by exceptional access |
| Normal Read → FeedbackResponseContent | Queries must never join FeedbackIdentityMapping (D-06) |
| Exceptional Read → FeedbackIdentityMapping | Requires ConfidentialIdentityView permission + audit event |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Information Disclosure | FeedbackResponseContent query paths | mitigate | Hard-separated storage (D-05); FeedbackResponseContent has no reviewer FK; queries never join FeedbackIdentityMapping |
| T-04-02 | Tampering | Threshold count via late withdrawals | mitigate | Threshold evaluated at window close (D-11); withdrawal removes from count (D-15); invalidation removes from count (D-17) |
| T-04-03 | Tampering | Feedback template after publish | mitigate | FeedbackTemplateSnapshot frozen at publish; immutable thereafter (like FormalReviewDefinitionSnapshot) |
| T-04-04 | Information Disclosure | Unauthorized identity resolution | mitigate | ConfidentialIdentityView permission required; every access emits FeedbackIdentityAccessed audit event (D-07/D-10) |
| T-04-05 | Tampering | Self-feedback submission | mitigate | SubmitFeedbackResponse validates reviewer != subject at submission time |
| T-04-SC | Tampering | npm/pip/cargo installs | accept | No new packages installed in this phase |
</threat_model>
