**Evidence file open — auth fix (2026-09-08, uncommitted).** Diagnosis: file "Open" was a plain `<a href="/api/…/evidence/{id}" target=_blank>` → **401**. App auth is a **Bearer JWT from `ey_hr_auth` localStorage** attached by the JS fetch client (`packages/api/src/client.ts:118`); the `ey_hr_auth=true` cookie is only a presence flag. A top-level anchor navigation carries no bearer (shell `/api` proxy forwards headers untouched, injects nothing) so `DownloadEvidence`'s `CanEnterPerformance(User)` fails. Fix (matches bearer model): `createPerformanceApi.downloadEvidence(cycleId, evidenceId)` = `client.get<Blob>(path, {responseType:"blob"})` (client already supported non-JSON `responseType`); `useEvidenceOpener(cycleId)` hook opens `about:blank` **synchronously in the click gesture** (dodges popup blocker), fetches the blob with auth, points the tab at `URL.createObjectURL(blob)`, revokes after 60s, exposes `openingId`. Timeline File "Open" is now a button (spinner while `opening`); **links stay plain anchors** (external, no bearer). `@repo/api` is source-transpiled (`exports: ./src/index.ts`, perf `transpilePackages`) so no build needed. Verified E2E as Nour: popup → `blob:http://localhost:3000/…`, `image/jpeg`, `<img>` loaded 675×1200. Evidence store = local `bin/…/evidence-store/{tenant}/{key}` (`Evidence:LocalRootPath` or default). type-check(api+perf)+lint green.
