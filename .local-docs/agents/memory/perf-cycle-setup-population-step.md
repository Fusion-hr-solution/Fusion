**4 backend correctness fixes (§7):**
1. Reviewer readiness beyond `manager != null`: added `ReadinessIssueCode.InactiveManager` (hard); resolver now flags inactive manager AND self-manager (self → MissingManager). Candidate carries `ManagerIsActive`/`HasValidReviewer`; resolution adds `ReviewerReadyCount`/`ReviewerRequiredCount`.
2. `GetAllActiveAsOfAsync` (CoreHR) now selects from active **employments** (not primary assignments), so an active employee with a broken/missing assignment stays visible with null OrgUnit → surfaces as `NoPrimaryAssignment` instead of silently dropping.
3. Org hierarchy as-of eligibility date: `useOrgHierarchy(enabled, asOf?)` param (endpoint already took `asOf`); population passes cycle start date.
4. Idempotent PUT: `PopulationDefinition.MatchesSelection(...)` normalized compare; `SetPopulationHandler` no-ops an equivalent re-send (keeps confirmation + participants), only an effective change reopens.
